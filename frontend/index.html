维度评分含义看多信号（正值）看空信号（负值）

三、信号使用指南

1. 综合信号解读

综合评分区间信号建议操作
+60 ~ +100🟢 强烈看多市场环境健康，可积极做多，仓位可维持80%以上
+30 ~ +60🟡 偏多整体向好但需关注风险信号，仓位60-80%
-30 ~ +30⚪ 中性方向不明，建议控制仓位在50%左右，等待明确信号
-60 ~ -30🟠 偏空风险信号增多，建议减仓至30-50%，以防御为主
-100 ~ -60🔴 强烈看空多项指标共振看空，建议仓位降至30%以下，或清仓观望

2. 多维度共振判断

  • 多个维度同时看空（如资金面+技术面+成交量同时为负）→ 高位见顶概率大幅提升，应高度重视
  • 北向资金连续3日净流出 + 两融余额见顶回落 → 资金面恶化，是重要的撤退信号
  • 美元走强 + 美债收益率上行 + SOX下跌 → 外部环境恶化，警惕A股跟跌
  • 成交额创阶段天量 + 涨幅收窄 → 典型的高位放量滞涨，顶部特征明显

3. 最佳使用时间

  • 开盘前（9:00-9:25）：查看隔夜美股利空、全球股指涨跌，判断当日开盘方向
  • 盘中（10:00-11:30, 13:00-14:30）：关注北向资金实时流向、成交额变化，判断日内走势
  • 收盘后（15:00-15:30）：查看两融余额更新、涨跌家数统计，复盘当日市场结构
  • 非交易日：回顾多日信号趋势，判断中期方向

预警名称级别触发逻辑应对建议

MACD顶背离预警 一级 股价创新高但MACD指标走低 → 上涨动能衰竭 ⚠ 经典顶部信号，建议分批减仓

利好兑现回落预警 三级 利好消息发布后股价冲高回落 → "买预期卖事实" 利好落地后不追高，警惕资金借利好出货

五、强制止损规则
